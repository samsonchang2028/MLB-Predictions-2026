## Script contract

- **Backfill:** `scripts/closing_odds_capture.py --backfill-from-odds-books --anchor earliest`
  - Reads `daily.jsonl` + `odds_books.jsonl`
  - Writes `state/predictions/odds_closes.jsonl`
  - Expected ~112–113 strict-window rows on current artifacts
- **Live:** same script, no flags — captures games in 60–15 min pre-first-pitch window; idempotent per `(run_date, game_pk, bookmaker, prediction_timestamp)`

## Systemd pattern (reuse OPS-001)

```text
deploy/systemd/mlb-predictions-daily.service  → User=mlbpred, EnvironmentFile, journald
deploy/systemd/mlb-predictions-daily.timer    → OnCalendar Pacific, Persistent=true
```

**Do not** wrap closing odds in `operator.lock` — daily predict holds that lock for DuckDB writes; closing odds only reads DuckDB and appends JSONL.

## Timer cadence

Every 10 minutes: prefer `OnCalendar=*-*-* *:00/10:00` or `OnUnitActiveSec=10min` + `OnBootSec=5min`. Script no-ops outside capture window.
