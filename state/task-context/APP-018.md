## User intent

Model Quality → Daily Monitoring should compare **Baseline PLAY** vs **raw
model favorite** picks, not only show baseline PLAY columns.

## Key semantic distinction

From `src/app/dashboard_analytics.py`:

- `picked_home(row)` — edge-selected side (sign of edge)
- `model_predicted_home(row)` — raw model favorite (`P(home) >= 0.5`)

On **crossover** games these differ. Journal `correct` reflects edge-selected
side; raw model needs separate `raw_model_correct`.
