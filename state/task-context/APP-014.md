# APP-014 Context Pack

## Task

Professor-readable Streamlit model monitoring tab.

Task file: `tasks/APP-014-professor-model-monitoring.md`

## Objective

Make the Model Quality page easier to explain to a data science professor and
add daily live monitoring results by slate date. Keep betting-selection results
separate from model-quality evidence.

## Relevant Existing Files

- `src/app/model_quality_page.py` - Streamlit Model Quality page.
- `src/app/dashboard_analytics.py` - artifact-backed app analytics helpers.
- `tests/unit/app/test_dashboard_analytics.py` - analytics helper tests.
- `reports/experiments/v1-holdout-2026.json` - final holdout artifact.
- `reports/experiments/v1-repaired-a910017bac839af5.json` - development report.
- `state/predictions/daily.jsonl` - immutable daily prediction rows.
- `state/predictions/journal.jsonl` - post-game result enrichment rows.

## Constraints

- Do not retrain.
- Do not change model, pipeline, market math, ADR-006, or artifact schemas.
- Daily metrics must use latest prediction per `game_pk`, matching existing
  dashboard policy.
- Journal joins must remain keyed by `(game_pk, prediction_timestamp)`.
- Pending games must be excluded from win rate and ROI.
- PASS rows must be excluded from PLAY win rate.
- Betting results are monitoring only, not model-quality proof.
