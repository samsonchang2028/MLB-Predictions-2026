## Known limitations

- Home and analytics pages require local artifacts (`state/predictions/*.jsonl`, holdout report) for full content; empty states are handled with info messages.
- Feature context on the home page depends on `state/predictions/game_features.jsonl` when present.
- Streamlit row selection for game detail requires running via `streamlit run streamlit_app.py` (multipage root).
- Prospective metrics are computed from stored predictions + journal outcomes, not a model re-run (by design).
