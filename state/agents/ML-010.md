## Why this is blocked, not done

This checkout has no local `data/mlb.duckdb` and no certified 2021-2026
dataset (data/ is gitignored; prior real builds were operator-run in a
different session/machine). 2026 has not been ingested or certified at all
as far as this checkout can tell. Running the real evaluation requires an
operator, on a machine with the certified DuckDB build, to:

1. Ingest and certify the 2026 season under the same DATA-006/DATA-007 rules
   already used for 2021-2025 (point-in-time safety, leakage checks,
   certification PASS) so a certification artifact covering 2021-2026 exists.
2. Run `python scripts/holdout_2026.py --certification <path-to-that-artifact>`
   (optionally `--database`, `--output`, `--random-state`).
3. Record the resulting `reports/experiments/v1-holdout-2026.json` metrics in
   `state/CURRENT.md` and this file, and only then move ML-010 to done.

No 2026 numbers are fabricated or guessed anywhere in this change.
