# MLB Agent Harness Pack

Copy these files into the root of the MLB moneyline predictor repository.

Start with:

1. `AGENTS.md`
2. `docs/project_execution_contract.md`
3. `docs/roadmap.md`
4. `state/CURRENT.md`
5. `tasks/META-001-agent-foundation.md`

After META-001 is committed, the next implementation node is DATA-001.

The repository is intentionally vendor-neutral. Codex, Claude Code, Cursor, a human developer, or another coding harness should all be able to operate from the same durable context.
